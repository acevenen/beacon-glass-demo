# BEACON — public demo pages

Hosted mirror of the BEACON spatial-leasing-intelligence demo, for loading onto Meta Ray-Ban Display glasses in developer mode. Full project (sales script, GTM plan, research paper) lives in the private `beacon-leasing` repo.

- `index.html` — Agent HUD / Ops Console / Vision (desktop or phone browser)
- `glass.html` — **BEACON GLASS**, the in-lens app. Point the glasses' web-app loader at this file's Pages URL.

All unit statuses are simulated; floor plans and pricing reflect Lumina Hollywood's public listings as of July 2026.
